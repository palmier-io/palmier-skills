# Palmier Pro edit direction

Mechanics (dissolve, key, keyframe) decide *how*; this decides *what and why*. Two failure modes to beat: **(a)** defaulting to your last style (every video looks the same), and **(b)** when asked to be "different," retreating to slow/calm/cinematic instead of adding **motion**. Fix both with a deliberate treatment **plus a mandated motion budget**. Read [[pro-editing]] first.

## Motion budget — NOT optional polish

A cut with hard cuts + a grade + a 9% Ken Burns *moves like a slideshow*. Every edit must spend a motion budget:

- **No static shots.** Every clip carries movement — a speed ramp, a punch-zoom, a pan, or a shake. If a shot just sits there, add motion or cut it.
- **≥1 speed-ramp hero moment** — slow-mo drifting then **slam to real-time on the beat** (use high-fps footage; retime via splits, see [[motion-keyframes]]).
- **Beat-punch zooms** — `scale` **hold-snap** 1.0→1.25+ on kicks/downbeats, not gentle drifts. The frame should *hit*.
- **Whip-pan / motion-blur transitions**, not only hard cuts (see [[transitions]]).
- **Rhythm with dynamics** — accelerate into the drop (half-beat machine-gun cuts), then release on a held slow-mo. Never a uniform grid (see [[beat-sync]]).
- **Punctuation:** strobe/black flashes, **camera shake** (rapid small `position` jitter keyframes), freeze-frame hits.

**Motion lives in the footage, not text on top.** Spend the budget on camera/frame movement — clean visuals read more premium than word overlays. Treat on-screen kinetic type as **opt-in only** (when the brief explicitly asks); default to none. A logo end card is fine; lyric/word overlays are not a default.

**Tool honesty:** palmier has no native glitch / RGB-split / datamosh. Approximate an aggressive "glitch" feel with strobe (rapid opacity/black flashes) + punch-zooms + whips + camera-shake + heavy `stylize.grain`.

## Treatment — commit to ONE bold look, chosen from the music

Don't default to your last grade. Pick a treatment as a **set** (grade + transition vocab + typography), matched to the track:

| Treatment | Grade | Motion signature |
| :-- | :-- | :-- |
| Neon Night | cold, high-contrast, saturated venue color | strobe cuts, punch-zooms, shake on drops |
| 35mm Film | filmic contrast, halation, heavier grain | speed-ramps, whip-pans, patient-then-explosive |
| VHS Raw | gritty, low-fi, chromatic edges (grain-heavy) | handheld shake, hard cuts + whips, lo-fi kinetic type |
| Warm Hype | warm glow + vignette | fast hard cuts, dip-to-black (⚠ already used) |

**Music-led:** cut density, energy, grade, and drop treatment derive from the track — trap/hip-hop → punchy, ramp-heavy, hard-hitting; house → rolling; downtempo → patient but still moving. Let the song pick the intensity.

## Don't repeat yourself

- **Signature-move rotation:** each edit features 1–2 hero techniques and **does not reuse last time's**. Warm-glow + dip-to-black is spent; the next is speed-ramp + punch-zoom + kinetic type, the one after is whip-cut + strobe, etc.
- **Style memory:** record the treatment + signature move of each delivered video (a running log) so the next is deliberately different. "Fresh" = new look + new signature, **not** less energy.

## Gotchas

| Symptom | Cause | Fix |
| :-- | :-- | :-- |
| "Not enough motion" | hard cuts + grade only; drifts too subtle | spend the motion budget — ramps, punch-zooms, whips, shake |
| Every video looks the same | defaulted to last grade/pacing | pick a new treatment from the palette, rotate the signature move |
| "Different" came out timid/slow | equated fresh with calm | freshness = new look + more motion, unless music demands calm |
| Zoom/push imperceptible | 9% Ken Burns | punch-snap 25%+ on the beat with hold interp |
| Reached for text overlays to add energy | text ≠ motion and can look cheap | get energy from ramps/zooms/whips/shake; keep kinetic type opt-in |
